# Comprehensive conflicts audit — lubricant raw-material data

Smart Formulator raw-material database (`Products_json`: 264 products, 706 JSON files). Branch `audit/comprehensive-conflicts` from `main` at `77ba590` (no newer commits on GitHub on 2026-10-30). Audit 2026-10-27; quality review 2026-10-27; source-verification review and reporting corrections 2026-10-30 (this version). No product JSON, template, coverage workbook, integration script or the curated log `open_questions_and_conflicts.md` was changed; no conflict was resolved, averaged or settled by preferring one document type. Every finding is listed with the same ID in `comprehensive_conflicts_audit.csv`; evidence copies and hashes are in `audit_evidence/` (see `audit_evidence/evidence_manifest.md`).

## Supervisor summary

**What was examined.** All 706 records of the raw-material database. The 147 conflict entries already recorded in the JSON (125 distinct conflicts) were checked against the exact pages and product columns of the cited supplier documents; independent checks then searched for unrecorded problems (internal consistency of every value, physical plausibility, API base-oil group definitions, and 1,116 comparisons with every other archive document naming the same product). Multi-product tables were read column by column; pages without a text layer were read on screen. External sources were obtained and archived with hashes (Petro-Canada 2023.03 brochure, S-OIL base-oil page, API 1509 Annex E, a Chevron Phillips data sheet, the ADNOC specification, PubChem registry records, archived Afton data sheets, a Richful product feed).

**What was found.** 180 finding records (IDs CF-001 to CF-180) in 72 products. One pair records the same disagreement twice (CF-093 duplicates CF-096), so there are 179 distinct issues.

| Type | Records | Meaning |
|---|---|---|
| Confirmed contradiction | 32 | Values for the same product and property that cannot both be right as printed, compared under comparable conditions, with no documented method, condition or edition that explains them. |
| Potential contradiction (comparability uncertain) | 13 | Values that appear to disagree, but the documents do not state enough (method, temperature, quantity, basis, date or grade level) to confirm that they are comparable. Not a confirmed contradiction and not an explained difference. |
| Edition difference | 100 | Values (or claims) that differ between dated editions, or editions of one document series, of the supplier's documents. |
| Explainable difference | 18 | Values that differ, but the documents themselves state a different method, condition, unit, bound type or classification basis. |
| Data-quality issue | 17 | A problem in how the JSON or a supplier document records a value, unit, label, derivation rule or identity. |
| **Total** | **180** | 179 distinct issues |

125 records were already recorded as conflicts (all preserved), 16 only as open questions, 9 only in field notes, 4 elsewhere (identity review, integration flags); **26 are new**. Two source groups deserve mention: **Petro-Canada PURITY** — 62 records representing 61 distinct issues (61 edition differences between LUB3213E 2015.07 and 2023.03; CF-093 duplicates CF-096); **S-OIL** — 24 records = 23 edition differences + 1 potential contradiction (CF-102: an SDS range compared with a web typical).

**Most important open issues.**
- Synfluid C12 Dimer pour point (data-quality): the archive sheet heads the column "°F, °C" but the values only fit °C (°F); the manufacturer's own sheet prints −53 °C (−63 °F), whereas the database stores −63 °C.
- Ergon HyGold L750 (confirmed contradiction): one data sheet prints density 0.854 g/cm³ and specific gravity 0.9183 at the same temperature; the SDS (0.92) supports the specific gravity.
- Richful RF6066, RF6069, RF6077 (confirmed contradictions): TDS and SDS kinematic viscosities at 100 °C differ by up to 24 mm²/s with the same method (RF6069 118 vs 142), and the two undated RF6066 TDS differ by 42 mm²/s; RF6077 density is lower at 15 °C than at 20 °C.
- Undocumented TDS vs SDS flash-point differences of 5–31 °C by the same open-cup method (confirmed: Chevron Phillips Synfluid PAO 4/6/8, mPAO 150; ExxonMobil SpectraSyn Elite 150).
- S-OIL Ultra-S 4 SDS (confirmed): the chemical name ("hydrotreated light paraffinic") and the CAS number (registered as "hydrotreated heavy paraffinic") do not match.
- aramcoPRIMA 70 (confirmed): the specification heading says Group II but allows a viscosity index below the API 1509 Group II minimum (76 vs 80).
- Sulfated ash (data-quality): the 26 estimated values use two different zinc factors — an inconsistent calculation method, which does not by itself show which factor or estimate is wrong; for Lubrizol CV1100 and CV3515 the estimates (5.8 and 9.2 wt.%) differ from the typical values printed in the products' own data sheets (7 and 10 % weight).

**Verification.** "Verified" means the evidence stated for the finding was checked in the source; it does not mean the disagreement was scientifically resolved or that every follow-up action is complete (definition in section 4). 176 records are verified, 3 partially verified and 1 pending. 8 items still need evidence that could not be obtained (High 1, Medium 5, Low 2; section 4).

**Follow-up needed.** No finding is resolved by this audit. The follow-up differs by finding; each record states its own reason:

| Follow-up | Records | Meaning |
|---|---|---|
| Supplier clarification | 44 | The documents cannot settle the question; the finding-specific reason states what only the supplier can provide. Suppliers were not contacted. |
| Edition-selection policy | 97 | Values differ between editions; a documented rule is needed for which edition supplies the working value. Supplier contact is not required unless an older value must be confirmed as obsolete. |
| Correctable from existing evidence (data owner) | 12 | The evidence already in the archive or the evidence folder is sufficient for the data owner to correct or annotate the record. Not done by this audit. |
| Data-owner decision (field-selection rule) | 9 | Values are compatible; the data owner should choose one consistent rule for which value the field holds. |
| Standard or further source needed | 7 | A standard (ASTM D874) or a further dated document is needed before the finding can be completed. |
| No follow-up needed beyond documentation | 11 | Not a disagreement, or a difference the documents themselves explain; both values stay documented. |

**Resolution labels.** Of the 14 records the database marks as resolved, 13 hold a working value (a newer dated edition, or a user decision of 2026-10-18) and one is a temperature note. The audit keeps these decisions but reports the underlying disagreements as unresolved (section 6). Three records are not value conflicts (the temperature note and two sets of claims changed between bulletin editions).

**Limitations.** ASTM D874 was not accessed, so the sulfated-ash calculation cannot be validated; two Afton editions could not be retrieved; suppliers were not contacted; 31 archive PDFs have no text layer (checked visually only where a finding depends on them); a value that coincides with another grade's value in a multi-grade table can escape automated comparison.

## 4. Verification: definition, status and pending items

**Definition.** "Verified" means that the evidence stated in the finding's verification text was checked in the cited source: the value, the product (and, in multi-product tables, the column), and the unit, qualifier, method, temperature and edition date wherever the comparison depends on them. It does **not** mean that the disagreement was scientifically resolved, that comparability is confirmed (see the comparability column), or that every follow-up action is complete. "Partially verified" means some of the stated evidence could not be obtained; "Pending" means the check could not be done; "JSON-only" means the issue lies in the data itself.

## 10. Limitations

- ASTM D874-23 (sulfated ash) is sold by ASTM and was not accessed; CAS Common Chemistry requires an API key (PubChem used instead).
- Suppliers were not contacted; the records marked "Supplier clarification" state what each would need to provide.
- Two Afton HiTEC 5748 editions (03/18, 04/21) could not be retrieved: the Internet Archive search was temporarily offline on 2026-10-30.
- 31 archive PDFs have no text layer and 13 files are images; DL2-13731.pdf uses an encoded font. These were read visually only where a finding depends on them.
- The automated comparison can miss a value that coincides with another grade's value in a multi-grade table.
- Physical checks use general relationships only (density falls with temperature; °F/°C conversion; API 1509 definitions); no viscosity index was recalculated.
