# Comprehensive conflicts audit — lubricant raw-material data

Smart Formulator raw-material database (`Products_json`: 264 products, 706 JSON files). Branch `audit/comprehensive-conflicts`, from `main` at commit `77ba590`; audit and quality review 2026-10-27. No product JSON, template, coverage matrix or the curated log `open_questions_and_conflicts.md` was changed, and no conflict was resolved, averaged or settled by preferring one document type. Every finding is listed, with the same ID, in `comprehensive_conflicts_audit.csv`.

## Executive summary

**Scope and method.** All 706 records were examined. The 147 conflict entries already recorded in the data (125 distinct conflicts) were checked value by value against the cited pages of the supplier documents in the project archive (347 PDFs and 13 images). Independent checks then looked for unrecorded problems: every value object was screened for internal inconsistencies (status, units, ranges, temperatures, physical plausibility, API group definitions), and each key property was compared with every other archive document that names the same product (1,116 comparisons). Each candidate was read in the source; pages without a text layer were checked visually where a finding depends on them. Nothing was resolved: both values and their sources are kept for every conflict.

**Findings.** 180 distinct findings in 72 products, in four types:

| Type | Count | What it means |
|---|---|---|
| Genuine contradiction | 47 | Incompatible values for the same product and property; no documented method, condition or edition explains them. |
| Edition difference | 100 | Values differ between dated editions (or editions of one document series) of the supplier's documents. |
| Explainable difference | 17 | Values differ, but the documents themselves state a different method, condition, unit or bound type; the values are not incompatible. |
| Data-quality issue | 16 | A problem in how the JSON or a supplier document records a value, unit, label, derivation rule or identity. |

125 findings were already recorded as conflicts (all preserved here unchanged), 16 were recorded only as open questions, 9 were noted only in field notes, 4 were recorded elsewhere (identity review, integration flags), and **26 are new**. 2 conflicts previously marked resolved need reconsideration.

**Most important open contradictions.** A pour point probably misread from a mislabelled °F/°C header (Synfluid C12 Dimer: stored −63 °C, the printed pair is only consistent as −53 °C); a density that contradicts the specific gravity on the same sheet (Ergon HyGold L750); a sulfur value printed as 1.3 ppm in one sheet and 1.3 wt.% in the other (aramcoDURA BS150); safety-data-sheet flash points below the product's own specification minimum (aramcoPRIMA 70; Richful RF6602); calculated sulfated-ash values that contradict the printed values (Lubrizol CV1100, CV3515) and two different zinc factors across 26 calculated values; three API group labels that conflict with the reported viscosity index; and undocumented TDS vs SDS flash-point differences of 5–31 °C (Chevron Phillips Synfluid, ExxonMobil SpectraSyn Elite 150).

**Outstanding verification before submission.** (1) 61 Petro-Canada PURITY edition differences rest on the 2023.03 LUB3213E brochure, read from a distributor-hosted copy that is neither registered in `source_registry.json` nor archived; registering and archiving this one document is the most important remaining step. (2) 24 S-OIL edition differences rely on the S-OIL web page registered as verified on 2026-10-22; a dated spot check is sufficient. (3) 16 other findings need a check or confirmation: 8 high (API 1509 and ASTM D874 texts, supplier confirmation, one image-only source), 6 medium and 2 low (section 4).

**Limitations.** 31 archive PDFs have no text layer and 13 files are images (one PDF uses an encoded font); 32 external sources were not re-fetched; the ASTM D874, D2270 and API 1509 texts are not in the archive; a value that coincides with another grade's value in a multi-grade table can escape the automated comparison. Any work by the teammate that is not yet on GitHub is not covered.

Findings touching that work are marked in the CSV column `affected_by_teammate_changes`.

Method: (1) normalise all 147 conflict entries (10 record formats) and look up every recorded value on its cited page; (2) run detectors over all value objects (status vs value, Reported without source, ranges, bound vs typical labels, printed vs recorded temperature, unit vs magnitude, density vs specific gravity, KV40 vs KV100, pour/cloud/flash order, saturates + aromatics, CCS/MRV order, API 1509 group definitions, cross-tier blocks, names and suppliers, Calculated vs printed values, every °F/°C pair in the archive); (3) compare each key property with every other archive document naming the product (1,116 comparisons, 196 candidates, each read; multi-grade tables read column by column); (4) compare open questions that mention a discrepancy with the conflict records; (5) read image or vector pages visually where a finding depends on them.

## 6. Previously resolved conflicts requiring reconsideration

## 9. Limitations

- Findings recorded only as open questions were re-checked in the archive where their verification label says so; the others are reported as recorded.
